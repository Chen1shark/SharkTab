# Edge Add-ons 商店资料（可直接粘贴到 Partner Center）

## 单一用途 / Single purpose

SharkTab 只做一件事：把 Edge 的新标签页替换成一个以搜索为中心、带时间与快捷入口的个人起始页。它不修改其他网站，不接管搜索，也不提供与起始页无关的功能。

## 权限用途 / Permission justification

- `favicon`：仅用于读取用户自行添加到快捷入口的站点图标，并在本扩展的新标签页里显示。扩展不会读取浏览历史，不用于广告、画像或分析。

## 远程代码 / Remote code

否。扩展不加载或执行任何远程代码；全部 JavaScript、CSS 与图标随扩展包一起分发。运行时只发起数据请求（favicon / 用户主动搜索），不下载可执行代码。

## 数据使用 / Data usage

不收集任何个人数据。快捷入口、搜索引擎选择和壁纸只保存在本地浏览器存储（localStorage / IndexedDB），不上传、不出售、不共享。无分析、遥测或广告 SDK。

### 详细描述（≥250 字符）

SharkTab 是一个专注、克制的新标签页，把每天打开浏览器的第一屏整理成安静的工作起点。

主要功能：

- 顶部显示 24 小时制时间、公历、星期与农历，每分钟更新一次。
- 中央搜索框支持 Bing、Google、百度三种搜索引擎，可随时切换并记住选择。
- 快捷入口以 6～8 列网格排列，支持添加、编辑、删除、长按拖动排序与多行折叠展开；图标自动识别，也可以上传自己的图标。
- 支持自定义壁纸：图片保存在本机 IndexedDB，刷新后自动恢复；界面显示在 30% 暗色遮罩和低透明度玻璃表面之上，亮色、暗色或高对比壁纸下仍保持清晰。
- 右下角常驻「···」入口，可新增快捷入口、更换壁纸或恢复默认背景；空白处右键同样可用。
- 磁贴右键支持在新标签页打开、复制链接、编辑与删除；另支持键盘快捷键与减少动效设置。

隐私方面，SharkTab 不收集、不上传任何个人数据；快捷入口、壁纸和设置只保存在本地。获取图标时会向用户所填网址或 icon.horse 发起请求，搜索时才会向所选搜索引擎发送搜索词。

第三方图标说明：本扩展显示的第三方网站图标仅用于导航指引，版权归各自所有者所有。相关名称与标识是其各自所有者的商标；SharkTab 与这些公司无隶属、赞助或背书关系。

如果你想要一个没有资讯流、没有推荐、没有账号体系的新标签页，SharkTab 会是一个安静的选择。

## 认证测试备注 / Notes for certification

1. 安装后在 Edge 新建标签页即可看到 SharkTab，无需登录或账号。
2. 搜索框输入任意文字后按 Enter，会用当前引擎打开搜索结果。
3. 点击搜索框右侧引擎图标可切换 Bing / Google / 百度。
4. 右下角「···」或页面空白处右键可新增快捷入口或更换壁纸；磁贴右键可复制链接、编辑/删除。
5. 添加 17 个以上快捷入口可验证两行折叠与展开按钮。
6. 自定义壁纸会保存到本地 IndexedDB，刷新新标签页后仍然保留。
